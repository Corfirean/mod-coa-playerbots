audience: players
title: Bots no longer repeat spells the game would reject
---
Bots now check the same requirements as the game before casting: spells that cannot be used while another aura is active (Taldaram's Torment in Cursed Form), spells that need a weapon in the off-hand or main-hand slot, and spells that need a totem item (Standard of Valiance, Serpent Ward). This removes dozens of failed casts per minute for several specs.
