audience: players
title: Bots that die in a dungeon run back from the entrance like players
---
When the server revives a player at the start of the dungeon after the spirit is released, a bot in the same situation now does the same thing and runs to the group on foot. Before, a bot inside a dungeon could be teleported to its leader once it was more than 100 yards away; inside a dungeon instance bots now only teleport to their leader when they are in a different instance.
