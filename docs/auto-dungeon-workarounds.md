# Костыли авто-данжей (на 2026-11-07)

Список всего, что сейчас заставляет ботов "проходить" подземелья в обход честной игры. Для каждого пункта: что делает, где в коде,
зачем появилось (что мешало) и как сделать правильно. Ветка `feat/bot-scaling-20261103`, модуль `module/src`, всё только в песочнице.

Условные обозначения риска: **[A]** прячет настоящую проблему и может испортить обычную игру ботов, **[B]** безобидный для теста обходной путь,
**[C]** только тестовая обвязка.

## 6. Что мешает сделать правильно (сводка по корням)

1. **Нет умения прыгать, спускаться и использовать вертикальные связки.** Один корень стоит за пунктами 1.1, 1.3, 1.6, 3.7. Навмеш не соединяет уступы, а бот не умеет прыжок.
2. **Падения сквозь пол.** Корень пунктов 1.2, 3.7 и части 1.1. Нужно найти, где именно и когда: логи `Fall:` показывают координаты (Market Row 2301/1187 и другие).
3. **Боты не умеют идти следом на скорости NPC.** Корень 1.5. Нужно следование с подстройкой скорости и ожидание NPC на контрольных точках.
4. **Нет клиента.** Корень 2.1, 2.2, 2.8, 2.9. Для ботов нужен общий слой "действия игрока", который честно проходит проверки сервера.
5. **События завязаны на скрипты босса, а не на прогресс.** Корень 2.3, 2.4, 2.7. Сначала выяснить, почему стандартный путь не срабатывает (бомба на бочку, кристалл зиккурата, ритуал Hakkar).
6. **Слабые боты (уровень и шмот).** Корень раздела 4.

## 7. Предлагаемый порядок разбора

1. Включить подробный лог падений ещё раз и собрать список точек (`Fall:`), исправить навмеш или убрать прямую ходьбу в этих местах.
2. Проверить завершение `NearTeleportTo` у ботов (подтверждение), чтобы все переносы в разделе 1 были надёжны.
3. Для каждого `[A]` из таблиц выяснить, почему честный путь не работает, и убрать костыль по одному, проверяя группой из 4 прогонов.
4. Только после этого трогать раздел 4 (шмот, таланты вместо множителей).

## 8. Отложено владельцем (2026-11-07)

- Вынести множители скейлинга в Manager (`CoaBots.Scaling.*` уже есть в конфиге; таблица `BOSS_TUNING` пока зашита в код). Скейлинг включён по умолчанию для подземелий и рейдов, то есть заденет и живой сервер после релиза: перед релизом нужно решить значения по умолчанию.
- Опция "боты сами ходят в подземелья и там одеваются". Учесть инцидент AutoQueueDungeon (массовое создание ботов): использовать существующих простаивающих ботов, случайный выбор и жёсткий предел.
